# 03_二叉树链式实现

## 一句话定位

一般二叉树塞数组全是空洞，链表还给自由：每结点 data 加 left、right 两个指针，树形随便长，代价是找双亲得从根搜。本模块的重头戏是凑齐 7 种遍历——先/中/后序各一个递归版、一个非递归栈版，再加层序。

## 核心概念

递归三版只差一行：访问根的时机。先序在进左子树之前，中序在左子树归来之后，后序等两棵子树都归来。递归并不神秘——系统调用栈替你记着"走到哪了"。那非递归要做的事就清楚了：自己拿一个栈，把系统干的事重演一遍。

非递归三版共用同一个骨架：p 非空就压栈、沿左链下降；p 走到 NULL（左边走不通了）就弹栈回头，转向右子树。栈里存的是路过还没处理完的结点，也就是回头路。三种序的差别只剩访问时机：先序入栈前访问（第一次到就输出），中序出栈时访问（左子树完毕才轮到自己），后序最麻烦——弹出前得知道右子树走没走完，所以多记一个 last_visited：栈顶的 right 非空且不是 last_visited 就转右，否则才访问自己。少了这个记号，右子树会被反复下钻，死循环。

层序是第七种：先被访问的结点其孩子也该先被访问，把栈换成队列，输出天然一层一层。

建树用带空标记的先序数组（-1 即 BITREE_NULL_FLAG 表示空子树），这是考研标准输入；注意空标记也要消费掉，兄弟子树的位置才不会错位。读实现时会看到一个 static：栈数组开 10 万个指针约 800KB，放进静态区免得压爆 8MB 的函数栈。最后记一个数：n 个结点 2n 个指针域，n-1 条边用掉 n-1 个，**剩 n+1 个空链域**——下一模块线索化全靠这批"废指针"。

## 复杂度表

| 操作 | 时间 | 空间 |
| --- | --- | --- |
| 递归三序 | O(n) | O(h) 系统栈，h 为树高 |
| 非递归三序 | O(n) | O(h) 显式栈 |
| 层序 | O(n) | O(w) 队列，w 为最大宽度，最坏 O(n) |
| 建树（先序+空标记） | O(n) | O(h) |
| 结点数 / 叶子数 / 深度 | O(n) | O(h) |

## 易错点 / 考点

1. 非递归中序的口诀"非空压栈向左，空了弹栈向右"，弹栈后忘了 p = p->right 是最常见的笔误。
2. 后序非递归没有 last_visited 必死循环：右子树访问完回到根，程序分不清"右子树走没走过"，会再次转向。
3. **序列反推唯一性**：先序+中序、后序+中序、层序+中序都能唯一还原二叉树；先序+后序不能（只有一个孩子时定不出左右）。手算套路固定：先序/层序定根，回中序切两半。
4. 叶子数 = 度为 2 的结点数 + 1（n0 = n2 + 1），按度数列方程几步就推出来，别死背。
