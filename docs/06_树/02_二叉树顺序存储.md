# 02_二叉树顺序存储

## 一句话定位

完全二叉树可以一个指针都不用：结点按编号塞进数组，编号 i 存 data[i]，左孩子 2i、右孩子 2i+1、双亲 i/2，父子定位全靠一次乘除。悬垂指针？不存在的，下标就是地址。

## 核心概念

2i/2i+1 不是拍脑袋规定的。完全二叉树逐层从左到右编号，每层结点数恰好是上一层的两倍，每个结点在下一层"占住"两个连续编号——左孩子拿偶数位，右孩子拿奇数位。自己在纸上给 i=2、i=3 排一遍，4,5,6,7 会自己冒出来，双亲 i/2 也顺势成立。**编号体系本身就把树形编进了下标**，这是顺序存二叉树的全部底气。

实现里有两个约定值得先说死。0 号单元弃用、下标从 1 开始：若从 0 编号，公式全变成 2i+1、2i+2、(i-1)/2，处处带偏移；从 1 开始则和教材一字不差，`data[SEQ_BT_MAX + 1]` 里闲着的 0 号格是买公式干净花的钱。其次，本模块用"层序连续追加"建树（sbt_insert_level 永远填 last+1），整棵树始终保持完全形态，编号关系恒成立。

这其实划出了顺序存储的适用边界：完全二叉树一格不浪费；一般二叉树就得按最坏形态补空位——深度为 k 的单支树只有 k 个结点，却要占 2^k-1 个格子，k 取 20 就是约百万个格子睡着一棵 20 结点的树。所以教材说顺序存储适合完全二叉树，堆就是活在数组里的完全二叉树；一般二叉树请交给下一模块的链表。

## 复杂度表

| 操作 | 时间 | 说明 |
| --- | --- | --- |
| 定位双亲 | O(1) | i/2 一次整除 |
| 定位左/右孩子 | O(1) | 2i、2i+1 各一次乘加 |
| 层序插入 | O(1) | 填 last+1，满则溢出 |
| 四种遍历 | O(n) | 每个有效编号访问一次 |

## 易错点 / 考点

1. **编号从 1 还是从 0 开始是两套公式**：教材默认从 1（左 2i、右 2i+1、双亲 ⌊i/2⌋）；从 0 开始则是 2i+1、2i+2、⌊(i-1)/2⌋。先看题目下标再套。
2. 判叶子不用看指针：编号 i > ⌊n/2⌋ 的结点必是叶子；顺手记 n 个结点的完全二叉树高为 ⌊log₂n⌋+1。
3. 手算浪费量：深度 k 的单支树按 2^k-1 个单元占位只用 k 个，别把数组长度当成结点个数。
4. 对完全二叉树，给一串层序序列就等于给定了整棵树——填空判断题常拿这条做反推。
