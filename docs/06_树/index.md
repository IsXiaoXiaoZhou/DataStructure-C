# 06 树

## 是什么

树是一对多的层级结构：除根外每个结点有唯一双亲，任意结点可以有多个孩子。
本分类共 7 个模块：先用双亲表示法、孩子链表、孩子兄弟表示法三种存储建立"树"的直觉，
再聚焦二叉树——顺序存储与链式实现、递归与非递归遍历、线索化、森林与二叉树转换，
最后落到哈夫曼树与并查集两个经典应用。

## 现实用途

层级/关系数据：文件系统目录、DOM 树、编译器语法树、哈夫曼压缩、数据库 B 树索引、并查集(连通性)。

## 学习建议

三种存储中孩子兄弟表示法是"树转二叉树"的钥匙，先读透，再顺着 森林与二叉树转换 打通互转；
二叉树链式实现重点吃透递归与非递归（栈模拟）遍历并动手对拍，然后学线索二叉树如何用空指针存前驱后继；
哈夫曼树亲手算 WPL 并生成编码；并查集掌握路径压缩与按秩合并
（见[工程规范](/guide/conventions)）。
