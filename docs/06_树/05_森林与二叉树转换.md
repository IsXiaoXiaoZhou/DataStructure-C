# 05_森林与二叉树转换

## 一句话定位

树和森林是多叉的，二叉树的整套结论（遍历、线索化、后面的各类算法）却最成熟——孩子兄弟表示恰好是座桥：first_child 当左孩子、next_sibling 当右孩子，任意森林都能无损变成二叉树，也能无损变回来。

## 核心概念

转换规则就两条，口诀"左孩子、右兄弟"。树内：第一个孩子挂成左孩子，下一兄弟挂成右孩子。树间：森林里第 i+1 棵树的根，挂在第 i 棵树根的右链上。转完之后，二叉树的根就是第一棵树的根，沿根的右链一路拆开就是森林的各棵树。于是有条秒判性质：一棵树转成的二叉树**根必无右子树**（树根没有兄弟）；反过来，根带右子树的二叉树背后必是森林。

王道考两条遍历性质：**森林的先序 = 对应二叉树的先序，森林的后序 = 对应二叉树的中序**。直觉不玄，拿孩子兄弟链走一遍就懂：森林先序是"访问自己、进 first_child、回来顺 next_sibling 访问下一棵树"，逐条对应二叉树的"访问自己、进左、进右"；森林后序是"子树全部完毕才轮到根"，映射到二叉树恰好是"左完毕、右完毕，中间访问自己"，即中序。

本仓库实现是复制式转换：转换后源森林与目标二叉树各自独立可读可销毁，main.c 用 roundtrip（森林→二叉树→森林）加"指纹"（先根序列 + 每结点孩子数序列）对拍验证互逆。两个方向都是 O(n)。

## 复杂度表

| 操作 | 时间 | 空间 |
| --- | --- | --- |
| 森林 -> 二叉树 | O(n) | O(n)，复制重建不共享结点 |
| 二叉树 -> 森林 | O(n) | O(n) |
| 森林先根 / 后根遍历 | O(n) | O(h) |
| roundtrip 指纹对拍 | O(n) | O(n) |

## 易错点 / 考点

1. 画转换图最常错的是树根的右链：第二棵树的根直接挂在第一棵树根的 right 上，多棵树就沿右链依次串，不是挂到"右孩子的什么地方"。
2. **森林后序对应的是二叉树中序，不是二叉树后序**。选择题爱问"森林的后根遍历序列等于转换后二叉树的哪序"，背反了全题皆输。
3. 转换是唯一的：给定森林，对应二叉树唯一；给定"根无右孩子的"单棵二叉树，还原回树也唯一。
4. 一棵树转出的二叉树根必无右子树，这条性质常被拿来做选择题秒判。
