# 03 队列

## 是什么

队列是先进先出（FIFO）的受限线性表：只允许队尾入队、队头出队。
本分类共 3 个模块：循环顺序队列用"取模回绕"解决顺序存储的假溢出问题，链队列靠头尾指针天然免于搬移，
最后以队列的应用集合（含多个独立算法演示）呈现舞伴问题这一经典场景。

## 现实用途

先进先出：打印/任务排队、消息队列、银行叫号。

## 学习建议

先读循环顺序队列，重点理解 front/rear 与取模运算如何复用出队腾出的空位，
以及"牺牲一个空位判满"的约定；再读链队列对比头尾指针的维护方式；
最后进入队列的应用集合（含多个独立算法演示），看舞伴问题如何用两个队列按性别分组、
轮流配对出队（见[工程规范](/guide/conventions)）。
