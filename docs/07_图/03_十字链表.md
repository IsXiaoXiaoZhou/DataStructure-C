# 03_十字链表

## 一句话定位

有向图的"邻接表 + 逆邻接表"合体：每条弧只建一个结点，同时挂在弧尾的出弧链和弧头的入弧链上，出边入边两条视角都顺链可得。

## 核心概念

先看清它治什么病。邻接表存有向图只挂出边，想知道"谁指向 v"——求入度、找入边——只能全表扫一遍 O(n+e)；补一张逆邻接表？空间翻倍，同一条弧存两份，改权还得改两处。

十字链表的办法是让弧结点长出四个指针字段：`tlink` 串"同弧尾"的下一条弧（出弧链），`hlink` 串"同弧头"的下一条弧（入弧链），每个顶点配 `first_out` / `first_in` 两个链头。一条弧物理上只有一个结点，从弧尾看它是出边、从弧头看它是入边，两条链十字交叉地穿过同一个结点，名字就是这么来的。于是**出度沿 first_out 数、入度沿 first_in 数，各 O(deg)**，邻接表的入度痛点到此了结。

共享结点是把双刃剑。插弧在两条链各头插一次，O(1)；删弧得在两条链上分别定位同一个结点、各改一次链接，但只 free 一次——漏摘一条链，另一条上就挂着悬垂指针。销毁更有意思：只沿出弧链释放就能覆盖全部弧，要是把入弧链也走一遍，每条弧会 free 两次，直接 double free。这份"删一次、摘两处"的谨慎，是十字链表实现的核心纪律。

## 复杂度表

| 操作 | 时间 | 说明 |
| --- | --- | --- |
| 空间 | O(n+e) | 每弧一个结点，双链共享 |
| 插弧 | O(1) 头插 | 本实现先沿出弧链查重，含查重 O(deg) |
| 判弧 / 删弧 | O(deg) | 沿弧尾的出弧链定位 |
| 出度 / 入度 | O(deg) | 各沿自家链数 |
| 销毁 | O(n+e) | 只走出弧链，走两边会 double free |

## 易错点 / 考点

1. **tlink、hlink 别背反**：tlink 接同弧尾（tail），hlink 接同弧头（head），字段名就是路牌，记住这组比背图快。
2. 删弧是"两链各摘一次、free 一次"：只摘出弧链，入弧链里留野结点；只 free 一次是本实现显式注释的坑。
3. 判弧沿弧尾的出弧链找 `headvex == head`，匹配字段是 headvex——从哪条链出发决定了该比哪个字段。
4. 只服务有向图；无向图"一条边存一份"的对应物是邻接多重表（04 模块）。另注意与"稀疏矩阵-十字链表"重名不重物：那边存矩阵非零元，这边存弧。
