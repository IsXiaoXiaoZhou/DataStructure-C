# 06_最短路径

## 一句话定位

Dijkstra 管单源——一个点出发到其余各点的最短路；Floyd 管全源——所有点对之间的最短路。一个贪心、一个动归，都架在邻接矩阵上，O(n²) 和 O(n³)。

## 核心概念

Dijkstra 为什么不能碰负权，一句话说透：它每轮把集外 dist 最小的点标记"确定，永不再改"，底气是**边权非负时绕路只会更远，已确定的最小值不可能被刷新**。有了负边这底气就没了。反例：S→A=1，S→B=2，B→A=-5。第一轮先锁 A（dist=1），之后才发现经 B 到 A 只要 -3——可 A 已锁死，答案错。所以本实现入口先全矩阵查负权，直接报错，不给静默的错解。流程 n 轮"选最小 → 入集 → 松弛出边"，prev 记前驱，终点沿 prev 回溯即得路径。

Floyd 的三重循环要读出含义：k 在最外层，第 k 轮结束 `dist[i][j]` 是"只许经过 0..k 号点中转"的最短路。每轮对所有 (i,j) 试借道：`dist[i][k] + dist[k][j]` 更小就更新，顺带把 `next[i][j]` 指向走向 k 的第一步，重建路径顺 next 走。它是递推——小中转集的解推出大中转集的解，k 放里层递推就断，拿半成品当已完成，答案必错。它能容负权边，容不下负权回路：绕一圈更小还能无限绕，最短路根本不存在。

哨兵细节：SP_INF 取 0x3FFFFFFF，两数相加不溢出 int；`dist[i][i]` 初始化 0，覆盖可能的自环弧。

## 复杂度表

| 操作 | 时间 | 说明 |
| --- | --- | --- |
| Dijkstra | O(n²) | n 轮 × 选最小 + 松弛一行 |
| Floyd | O(n³) | 三重循环，k 必须在最外层 |
| Dijkstra 空间 | O(n) | dist / prev / done |
| Floyd 空间 | O(n²) | dist 与 next 两张矩阵 |

## 易错点 / 考点

1. **手算 Dijkstra 每轮两步别混**：先圈"未确定中 dist 最小"的点，再只松弛它的出边；并列取编号小的（本实现取首个）。
2. Floyd 手算按 k 一轮一轮更新整张矩阵；考题爱问"k 放最里层行不行"，答不行——递推被打断。
3. "Dijkstra 能否处理负权"——不能，写上"锁死点被负边翻盘"，光背结论不给分。
4. Floyd 的 dist[i][i] 恒为 0；不可达保持 INF，别把 INF 当普通大数反复相加——哨兵再大，乘起来也溢出。
