# 07 图

## 是什么

图是多对多的网络结构：任意两个顶点之间都可能有边相连，是线性表与树的推广。
本分类共 8 个模块：邻接矩阵、邻接表、十字链表、邻接多重表四种存储各配 DFS/BFS 遍历演示，
算法部分则是"全家桶"——最小生成树（Prim/Kruskal）、最短路径（Dijkstra/Floyd）、
拓扑排序（Kahn/DFS 逆后序）与关键路径（AOE）。

## 现实用途

网络/关系建模：地图导航(最短路)、社交网络、物流(最小生成树/关键路径)、依赖调度(拓扑)。

## 学习建议

先读邻接矩阵与邻接表两种主流存储，各跟一遍 DFS/BFS（含非递归版本，分别用栈与队列模拟）；
四种存储不必平均用力，十字链表与邻接多重表理解有向弧/无向边的插删思路即可。
算法页按 最小生成树 → 最短路径 → 拓扑排序 → 关键路径 的顺序推进，每种都动手画图跟一遍
（见[工程规范](/guide/conventions)）。
