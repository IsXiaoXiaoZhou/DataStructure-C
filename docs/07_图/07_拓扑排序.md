# 07_拓扑排序

## 一句话定位

给有向图的所有顶点排一个"先决条件全排在前头"的线性序（AOV 网的执行顺序），顺带免费回答"图里有没有环"——拓扑序和环，有你就没我。

## 核心概念

Kahn 入度削减法的画面感最强：入度为 0 的点没有前驱，随时可输出；输出后把它所有出边邻居的入度减 1，减到 0 的接棒上场，一层层剥洋葱。本实现连队列都没建，每轮线性扫"未输出且入度为 0"的最小编号点，把"削减"这个动作明明白白摆在循环里，教学上反而更透。

环检测是这个算法的赠品，也是常考点：**Kahn 走完输出个数小于 n，剩下的点必构成环**——有向环上每个点都有一个环内前驱，入度永远减不到 0。另一条路是 DFS 逆后序：顶点递归返回（"完成"）时压栈，全部结束后按完成序的逆序输出。道理在于 u 比 v 先完成，图里就不可能有 v→u 的路径——有的话 u 得等 v 完成后才轮到自己完成。它的环检测换用三色标记：访问到"进行中"的灰点就是回边、即有环；"已完成"的黑点是交叉边，安全的。

两法本实现都是邻接矩阵上的 O(n²)，换成邻接表就是标准答案 O(n+e)。接口里还带一个 `topo_verify`：检查每条弧 (u,v) 是否满足 u 排在 v 前，自己写的拓扑序先过一遍它再说。

## 复杂度表

| 操作 | 时间 | 说明 |
| --- | --- | --- |
| Kahn | O(n²) | 每轮扫 0 入度点 + 削减出边；邻接表版 O(n+e) |
| DFS 逆后序 | O(n²) | 每点扫一行邻居；邻接表版 O(n+e) |
| topo_verify | O(n²) | 每条弧查前后位置 |
| 空间 | O(n) | 入度表 / 颜色表 / 完成栈 |

## 易错点 / 考点

1. **拓扑序不唯一**：每轮 0 入度点常有多个，选谁都合法，本实现取最小编号只是钉死一种输出。答题判断"这个序合法吗"，别找"唯一序"。
2. Kahn 判环看输出个数，不是看还有没有点没碰：count < n 即有环，环上点入度永不为 0。
3. DFS 法判环靠灰色（递归栈中）点：撞见黑点只是交叉/前向边，把颜色偷懒成 visited 布尔，就会把无环图误判成环。
4. 逆后序 ≠ DFS 访问序的逆序：访问序（第一次踩到）的逆序可能把后继排到前驱前面，必须用完成时刻。
