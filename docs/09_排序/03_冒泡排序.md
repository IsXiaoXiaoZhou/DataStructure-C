# 03_冒泡排序

## 一句话定位

相邻两个元素两两比较，逆序就交换，一轮下来最大的元素顶到末尾——像大气泡先浮出水面，一轮确定一个数，最多 n−1 轮收工。

## 核心概念

过程看 bubble_sort.c：end 从 n 收缩到 2，内层从下标 1 扫到 end，比较 a[i-1] 和 a[i]，逆序就交换，一轮走完区间里最大的元素一定落在末尾，下一轮少看它一眼。**第 k 轮结束后，数组最后 k 个位置就是全局最大的 k 个元素且已有序**——模拟题判中间状态，先拿这条核对尾巴。

提前判停是这份实现的点睛之笔：每轮开头置 swapped = 0，一轮下来一次都没换，说明区间已经有序，break 走人。已有序的输入只比较 n−1 次就退出，最好情况因此是 O(n)；没有这个标记，冒泡对任何输入都死板地比 n(n−1)/2 次。选择题爱抠"冒泡最好情况 O(n) 的前提"——前提就是这个 swapped。

稳定性照例看符号：`a[i-1] > a[i]` 严格大于才交换，相邻相等时不动，稳定成立；写成 `>=` 不仅破坏稳定，还对相等元素做一堆白费的交换。动画单步走一遍，注意每轮的比较波次，和末尾逐渐"凝固"的有序区。

## 复杂度表

| 场景 | 复杂度 | 说明 |
| --- | --- | --- |
| 最好（已有序） | O(n) | 靠 swapped 提前停 |
| 最坏/平均 | O(n²) | 比较量级 n(n-1)/2 |
| 空间 | O(1) | 原地 |
| 稳定性 | 稳定 | 相邻相等不交换 |

## 易错点 / 考点

1. **手算会错在扫描范围**：第 k 轮只扫前 n−k 个位置，已沉底的尾巴不再参与。抄每轮结束后的数组时，尾巴是从后往前逐个"凝固"的，别把整段都翻一遍。
2. 反向冒泡（每轮把最小值顶到最前）结论对称：第 k 轮后开头 k 个位置有序。题目换成这个方向时别套错结论。
3. 与插入排序的对比：两者最好都 O(n)、都稳定、都原地，但动作不同——冒泡靠交换，插入靠移位。冒泡的交换次数等于逆序对数，插入的移动次数也等于逆序对数，这个等式偶尔出现在选择题里。
