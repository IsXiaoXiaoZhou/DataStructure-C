# 06_堆排序

## 一句话定位

把数组下标当成完全二叉树的坐标用，先建一个父不小于子的大根堆，再反复把堆顶最大值换到末尾——本质是选择排序，只是"挑最大"从 O(n) 扫描升级成了 O(log n) 下沉。

## 核心概念

隐式树上没有一根指针：0 基数组里下标 i 的孩子是 2i+1 和 2i+2，父亲是 (i−1)/2，父子关系全靠算。注意本仓库有两套下标：heap_sort.c 排序部分用 0 基；`DsHeap` ADT 用 1 基（元素存 buf[1..size]，buf[0] 留空，父 = i/2 恰好整除），打开 heap_sort.h 对照头注释能对上号。

建堆为什么从 n/2 − 1 开始倒着调？下标超过 n/2−1 的全是叶子，单结点天然是合法堆，不用调；从最后一个非叶结点倒着 sift_down 到根，**保证下沉到每个结点时它的两棵子树已经是堆**——下沉逻辑（和较大的孩子换、换完继续往下）正是建立在这个前提上的。整趟建堆是 O(n) 而不是想当然的 O(n log n)：一半结点是叶子只出一次场，越靠上层结点越少，虽然单次下沉深，摊下来总和是线性的。

排序阶段：堆顶 a[0] 是全局最大，与当前堆的最后一个元素交换，堆规模减一，新堆顶下沉归位；重复 n−1 次，最大值从尾部往前逐个就位。动画里"交换 + 下沉"都演了，单步盯住堆顶和末尾这两个位置最清楚。

## 复杂度表

| 阶段 | 复杂度 | 说明 |
| --- | --- | --- |
| 建堆 | O(n) | 自底向上逐个下沉 |
| 排序 | O(n log n) | n−1 次"交换堆顶 + 下沉" |
| 最好/最坏/平均 | O(n log n) | 不看输入脸色 |
| 空间 | O(1) | 原地 |
| 稳定性 | 不稳定 | 堆顶换末尾是远距离交换 |

## 易错点 / 考点

1. **手算建堆最常错在顺序**：必须从最后一个非叶结点（0 基 n/2−1）倒着调到根。考题问"n=8 时第一个调整的下标"，0 基答 3、1 基答 4——先看清题目用哪套下标。
2. 大根堆排升序、小根堆排降序，别背反；追问"为什么不拿小根堆排升序"：每次取出的最小值要往前放，而堆的缩减发生在尾部，两头对不上。
3. 第 i 趟结束后数组末尾 i 个元素是全局最大的 i 个且有序——和冒泡同款结论、方向相反，判断题常拿这两个对照考。
