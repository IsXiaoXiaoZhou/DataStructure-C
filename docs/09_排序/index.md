# 09 排序

## 是什么

排序让数据有序，从而支撑后续的查找与展示。
本分类共 10 个模块：插入（直接插入/希尔）、交换（冒泡/快速）、选择（简单选择/堆）、
归并、计数、基数共九种内排序各成一页；外部排序应用集合（含多个独立算法演示）
覆盖败者树、置换选择排序、最佳归并树与外部多路归并。

## 现实用途

让数据有序以支撑查找与展示：排行榜、按价/时间排序、数据库 ORDER BY、海量数据外部排序。

## 学习建议

按 插入 → 希尔 → 冒泡 → 快速 → 简单选择 → 堆排序 → 归并 → 计数 → 基数 的顺序逐个过，
每个都亲手复现，并从"时间复杂度/稳定性/是否原地"三个维度做总结；快排的 partition 与堆排序的
下沉调整是笔试面试高频，务必吃透；最后进入外部排序应用集合（含多个独立算法演示），
理解败者树如何支撑多路归并、置换选择如何生成初始归并段、最佳归并树如何规划归并顺序
（见[工程规范](/guide/conventions)）。
