# 08 查找

## 是什么

查找是"从海量数据中快速定位目标"的功夫，本分类是一整套为此服务的结构族。
本分类共 12 个模块，是全站页面最多的一章：先打静态表基础（顺序查找、折半查找(含插值/斐波那契)、分块查找），
再进入动态树形结构（二叉排序树、平衡二叉树、红黑树、B 树、B+ 树），
最后以散列函数与两种冲突处理（拉链法/开放定址法）收尾，并配散列查找性能分析。

## 现实用途

从海量数据快速定位：数据库/字典索引、登录校验、缓存、倒排索引、哈希表。

## 学习建议

静态部分快速过一遍折半查找的边界写法即可；把主要精力投给树形结构：
二叉排序树先写熟插入与删除，平衡二叉树体会四种旋转，红黑树重点理解"近似平衡"为何工程上更受青睐，
B 树/B+ 树面向磁盘理解阶与分裂合并；散列部分动手实现拉链法与开放定址法，
再做性能分析对比（见[工程规范](/guide/conventions)）。
