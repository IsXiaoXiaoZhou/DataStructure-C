# 05_平衡二叉树

## 一句话定位

BST 的防退化补丁：任何结点的左右子树高度差不超过 1，失衡了就用旋转当场扭回来，把最坏 O(n) 压回 O(log n)。

## 核心概念

上一节看到，有序插入会把 BST 拉成一条链。AVL 的治理思路不改变 BST 的性质，只加一条硬约束：每个结点的平衡因子 BF = 左子树高 − 右子树高，必须落在 {−1, 0, 1} 里。约束管住了树形——n 个结点的 AVL 高度至多约 1.44·log₂n，查找的路径长度从此有了下限保证。

维护这条约束靠四种旋转，判断方法可以练成手感：找到失衡结点 x，朝插入方向往下数两步——左左（LL）是左孩子的左边重，整棵右单旋，把左孩子提起来当根；右右（RR）对称地左单旋；左右（LR）和右左（RL）是"拧了两次"的形态，先对孩子反向小旋一次把重孙拉成直接孩子，再对 x 做同侧单旋。一句话记：**同侧单旋、异侧双旋，双旋的两步方向相反**。rebalance 里 LL 与 LR 的区分只看 `h(x->left->left)` 和 `h(x->left->right)` 谁大，左孩子的左边不轻于右边就是 LL。

有个实现细节值得对着 avl.c 看：教材存每个结点的 BF，本实现存的是 height（叶为 1），BF 用时现场算——rebalance 开头一句 `bf = h(x->left) - h(x->right)` 就是。两种存法功能等价，存高度还省掉了插入时 BF 的级联修正。另一个容易被忽略的机制是"插入只转一次"：回溯时每个祖先都会调 rebalance，但旋转恰好把子树高度还原成插入前的值，上面的祖先自动痊愈，全树至多动一次刀；删除则可能一路失衡到根，这是插入与删除的本质差别。

## 复杂度表

| 操作 | 时间复杂度 | 说明 |
| --- | --- | --- |
| 查找 | O(log n) | 高度 ≤ 1.44·log₂n |
| 插入 | O(log n) | 至多 1 次旋转（单旋或双旋） |
| 删除 | O(log n) | 可能自底向上旋转 O(log n) 次 |
| 空间 | O(n) | 每结点多存一个 height |

## 易错点 / 考点

1. **旋转类型判断**：从最小失衡子树的根出发，沿"新增高度的方向"数两步定 LL/LR/RR/RL。最常见的错是把 LR 认成 LL——只看到 x 左重，没看重量的来源在左孩子的哪一侧。
2. 双旋顺序与方向：LR 是先对左孩子左旋、再对失衡点右旋，两步方向相反；写成同向直接破坏 BST 性质。手算时每步画图，旋完检查中序仍升序。
3. 最小失衡子树要找准：旋转对象是"离插入点最近的 BF 绝对值超 1 的结点"，不是它的孩子也不是根；插入情形调整这一个结点即可，别把整条路径都转一遍。
4. 删除与插入不同：删除后子树变矮会让祖先继续失衡，旋转要沿路径向上可能做多次——"插入至多转一次、删除可能转 O(log n) 次"是高频判断题。
