# 05 串

## 是什么

串（字符串）是内容受限的线性表——元素限定为字符，因此存储与匹配都有了专门玩法。
本分类共 5 个模块：定长顺序串、堆分配串、块链串三种存储各成一体，
模式匹配部分从朴素匹配（BF）进阶到 KMP 算法（next 与 nextval 数组）。

## 现实用途

文本处理：搜索匹配(KMP)、查找替换、DNA 序列比对、日志关键字检索。

## 学习建议

先读定长顺序串与堆分配串，理解预分配、堆上动态分配与块链存储的取舍；
再按 朴素模式匹配 → KMP算法 的顺序攻模式匹配：先写 BF 感受主串指针回溯的低效，
再吃透 next/nextval 数组的手算推导——KMP 是本章也是考试的重点难点
（见[工程规范](/guide/conventions)）。
