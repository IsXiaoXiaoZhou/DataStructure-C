# 02_两栈共享空间

## 一句话定位

两个栈挤在同一段定长数组里：栈 1 从左端向右长，栈 2 从右端向左长，中间空闲区两边共用。它治的是独立定长栈的浪费——各自为政时，一个栈满了另一个还空着，空间也借不过去。

## 核心概念

两个独立的定长栈各有 MAX 格，哪怕栈 2 一个元素都没有，栈 1 满了照样报溢出。共享空间把两个栈底钉在数组两端：top1 初始 -1、top2 初始 MAX，栈 1 的元素占 [0, top1]，栈 2 占 [top2, MAX-1]，中间的开区间 (top1, top2) 是共用空闲区，**两栈容量此消彼长、互相调剂**，只有整段数组真正用尽才报满。两个栈的需求量互补（一个大另一个往往就小）时，这套设计最划算。

判满条件 `top1 + 1 == top2` 的含义是空闲区长度为 0：此时压哪个栈都无格可写，满的是共享空间，不是哪个栈。shared_stack.c 里每次 push 都先判满再动下标，**顺序反了就会把值写进对方区间**——头文件注释把"两栈元素区间永不交叉覆盖"称作本结构唯一要守住的不变量。

方向感要建立起来：栈 2 向左生长，压栈是 `data[--top2] = value`，出栈后 `top2++` 把格子还回空闲区；判空分两套——栈 1 空是 `top1 == -1`，栈 2 空是 `top2 == MAX`，各自退到端点之外即空。

## 复杂度表

| 操作 | 时间复杂度 | 说明 |
| --- | --- | --- |
| 任一栈进栈 | O(1) | 先判满，再按栈号自增/自减下标 |
| 任一栈出栈 | O(1) | 取值后下标退回，格子归还空闲区 |
| 取栈顶 / 判空 | O(1) | 判空按栈号走两套条件 |
| 判满 | O(1) | top1+1 == top2，两栈共用 |
| 空间 | O(MAXSIZE) | 定长 100，是两栈容量之和的上界 |

## 易错点 / 考点

1. 栈 2 判空是 `top2 == MAX`，手算最常顺手写成 0 或 MAX-1。栈 1、栈 2 各有一套坐标，先分清再动笔。
2. 判满只有一条 `top1 + 1 == top2`（教材等价写法 `top1 == top2 - 1`），两栈共用；满时压任一栈都溢出，与压谁无关。
3. 元素个数：栈 1 有 top1+1 个，栈 2 有 MAX-top2 个，两者之和不超过 MAX；剩余空闲格数即 `top2 - top1 - 1`，题目常给一个中间状态让你数这个。
