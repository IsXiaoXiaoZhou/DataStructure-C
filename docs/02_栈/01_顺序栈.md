# 01_顺序栈

## 一句话定位

栈是操作最受限的线性表：只准在栈顶一端进出。顺序栈用定长数组实现它——一段连续内存加一个栈顶下标 top，所有动作都落在数组末尾那一格上。

## 核心概念

放盘子、取盘子都只碰最上面那只，栈的全部纪律就这一条：后进先出。本仓库用 `data[0..top]` 存元素，**top 指向栈顶元素本身，空栈约定为 -1**。这个约定决定每个函数的写法：进栈是 `data[++top] = value`，先自增腾出栈顶格再存值；出栈先取 `data[top]` 再 `top--`。顺序不可颠倒——出栈若先减后取，返回的就成了下一层的元素，栈空时更会读到 `data[-1]` 越界。

教材里还有另一派约定：top 指向下一个空位，空栈为 0，进栈先存值后自增，判满是 `top == MAXSIZE`。两派没有对错，但判空、判满、进出的语句顺序整套跟着变，**混用必错**。看懂"约定决定代码"这一点，seq_stack.c 里每个先加还是后减都不必死记。

两个顺手的细节：`stack_size` 返回 `top + 1`，空栈的 -1 加 1 恰好折成 0，不用特判；`stack_destroy` 只复位 top——静态数组没有内存可释放，残留数据在逻辑上已不可达，逐格清零是白费功夫。

## 复杂度表

| 操作 | 时间复杂度 | 说明 |
| --- | --- | --- |
| 进栈 push | O(1) | 判满后一次自增加一次赋值 |
| 出栈 pop | O(1) | 取栈顶值，top 减一 |
| 取栈顶 peek | O(1) | 只读 `data[top]`，不动 top |
| 判空 / 判满 / 求长 | O(1) | 一次比较或一次加法 |
| 空间 | O(MAXSIZE) | 编译期定长 100，无动态内存 |

## 易错点 / 考点

1. **top 初值两派是手算第一坑**。题目给 top 的值求元素个数：指元素派是 top+1（空栈 -1），指空位派是 top（空栈 0）；判满一派是 `top == Maxsize-1`，另一派是 `top == Maxsize`。动笔前先确认题目用哪派，别背死一个公式。
2. 语句顺序也是约定的推论：指元素派进栈先加后存、出栈先取后减，指空位派正好相反。把 `data[++top]` 手滑写成 `data[top++]`，top 为 -1 时直接写进 `data[-1]`。
3. 出栈序列合法性手判：按给定入栈序列模拟，目标序列要谁就把元素压到谁、随即弹出；轮到它时顶上不是它即非法。如入栈 1,2,3,4、出栈 4,1,3,2——4 出来后 1,2,3 都压在栈里，顶上是 3，1 要不到。合法出栈序列共 C(2n,n)/(n+1) 个（卡特兰数）。
