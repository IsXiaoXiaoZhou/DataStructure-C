# 02 栈

## 是什么

栈是后进先出（LIFO）的受限线性表：只允许在栈顶一端插入与删除，最先入栈的元素反而最后出栈。
本分类共 4 个模块：顺序栈、两栈共享空间、链栈三种实现，外加一个栈的应用集合（含多个独立算法演示），
把括号匹配、表达式求值与递归三个经典场景串成一条线。

## 现实用途

后进先出：函数调用栈、撤销/重做、浏览器后退、括号与表达式求值。

## 学习建议

先读顺序栈建立"栈顶下标 + 入栈出栈"的直觉，再读两栈共享空间体会两端向中间生长的空间复用设计，
然后读链栈对比不透明指针下的链式实现；最后进入栈的应用集合（含多个独立算法演示），
按 括号匹配 → 表达式求值 → 递归 的顺序，看栈如何把"后进先出"变成解题工具
（见[工程规范](/guide/conventions)）。
