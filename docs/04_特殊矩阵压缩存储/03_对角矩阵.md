# 03_对角矩阵


## 一句话定位

三对角矩阵（带状矩阵）：只有 |i-j| ≤ 1 的三条对角线可能非零，带外全是 0。非零元恰好 3n-2 个，压进长度 3n-2 的一维数组——n=1000 时 100 万个单元只剩 2998 个，是本章压缩比最高的一类。

## 核心概念

带状矩阵和三角矩阵有个本质差别：带外是真 0，不是常数 c。0 不用存也不用记，这反而让接口语义更干脆——get 到带外直接返回 0；set 往带外写 0 是无副作用的空操作，写非零值则被拒绝，因为压缩数组里根本没有它的位置。对比一下：三角矩阵的带外写得进（改 c），对角矩阵的带外写不进（拒绝），原因就在带外是"同一个数"还是"全是 0"。

先数非零元：第 1 行 2 个（a11, a12），第 2 到 n-1 行各 3 个，第 n 行 2 个，合计 2 + 3(n-2) + 2 = 3n-2。**首末行各少一个**，这就是总数是 3n-2 而不是 3n 的原因。

映射公式 k = 2i + j - 3，推导还是老套路"第 i 行前面有几行"：前 i-1 行共 2 + 3(i-2) = 3i-4 个（首行 2 个、中间各行 3 个）；第 i 行的行内首元是 a(i, i-1)，行内偏移 j-(i-1)。合计 k = (3i-4) + (j-i+1) = 2i + j - 3。按行序存出来就是

```
data = [a11, a12, a21, a22, a23, a32, a33, ..., a(n,n-1), ann]
```

验证：(1,1)→0，(1,2)→1，(2,1)→2，(3,2)→5，和手点数组一致。

## 复杂度表

| 操作 | 复杂度 | 说明 |
| --- | --- | --- |
| matrix_create | O(n²) 时间 | 扫一遍原始矩阵，只提取带内元素，带外值被忽略 |
| matrix_get | O(1) 时间 | 带外直接返回 0，不访问压缩数组 |
| matrix_set | O(1) 时间 | 带外写非零值被拒绝（DS_OUT_OF_RANGE） |
| 存储空间 | 3n-2 | 三条对角线的全部非零元 |

## 易错点 / 考点

- 非零元个数背成 3n：首行没有 a(1,0)、末行没有 a(n,n+1)，两头各少 1 个，所以是 3n-2。选择题爱在这里挖坑，n=1 时这个公式还能退化成 1，照样成立。
- 公式代串：k = 2i + j - 3 只属于三对角，别和下三角的 i(i-1)/2 + j - 1、上三角的 (i-1)(2n-i)/2 + j - 1 记混。三张公式表放一起对比着背，比单个硬记靠谱。
- 带外行为两副面孔：get 带外返回 0 是正常结果；set 带外写非零值报 DS_OUT_OF_RANGE。手算题问"压缩数组中有没有 a(2,5)"，答案是既没位置也不该有——它恒为 0。
- 反向定位：给 k 反求 (i, j) 时注意每行非零元个数不齐（首末行 2 个、中间 3 个），不能像三角矩阵那样套等差数列统一定位，按 3i-4 分段找行更稳。
