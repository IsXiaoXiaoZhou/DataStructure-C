# 02_三角矩阵


## 一句话定位

下三角矩阵：主对角线以上全为同一个常数 c；上三角矩阵反之。有效区只有 n(n+1)/2 个元素，压缩数组在末位再多开 1 个单元专门存 c，共 n(n+1)/2 + 1 个——比对称矩阵多的那 1 个，就是给 c 的家。

## 核心概念

和对称矩阵的区别一句话能说完：对称矩阵的上三角是下三角的镜像，可以共享存储；三角矩阵的带外不是镜像，是清一色的常数 c，没东西可共享，只能单独找个单元记下来。c 放在压缩数组末位（下标 n(n+1)/2），"带外全为 c"这条矩阵语义在存储层就保住了。

下三角模式的映射和对称矩阵完全一样：i ≥ j 时 k = i(i-1)/2 + j - 1（"第 i 行前面有几行"的推导见上一篇，不再重复）。上三角换成按行存 [a11..a1n, a22..a2n, ..., ann]，第 i 行有 n-i+1 个元素，前 i-1 行累计的是一个首项 n、末项 n-i+2 的等差数列，共 (i-1)(2n-i+2)/2 个；行内偏移 j-i。整理得

```
k = (i-1)(2n-i)/2 + j - 1
```

拿 n=4 的 (2,3) 验证：k = 1×(8-2)/2 + 3 - 1 = 5，手点数组 [a11, a12, a13, a14, a22, a23]，data[5] 正是 a23。

带外的读写是本模块最巧的一处：**带内带外共用同一套映射**。storage_index 对带外位置统一返回末位下标，于是 get 读到的自然是 c，连分支都不用写；set 写带外则是改 c 本身。注意这意味着写任意一个带外位置，全部带外元素的取值都会跟着变——这不是 bug，而是"带外为同一常数"这个定义在存储层的直接体现。

## 易错点 / 考点

- 上三角公式 k = (i-1)(2n-i)/2 + j - 1 最容易背串成下三角的 i(i-1)/2 + j - 1。判断依据是数组长相：上三角按行存时第 1 行最长（n 个），所以"前面有几行"要用等差数列倒着累，不是 1+2+...+(i-1)。
- 行内偏移方向：上三角第 i 行从 a(i,i) 开始，偏移是 j-i，不是 j-1。手算拿 (1,1) 验最稳：两个公式都应得 k=0。
- 带 1 与不带 1 的坑：压缩数组长度是 n(n+1)/2 + 1，末位单元下标是 n(n+1)/2。选择题问"n 阶下三角矩阵压需多少存储单元"，答 n(n+1)/2 就丢了常数 c 那 1 分。
- 写带外元素的行为：本仓库 set 带外 = 修改 c，所有带外元素一起变。手算题若问"写 a(1,n)（下三角带外）后 a(2,n-1) 的值"，答案是跟着变的新 c，别答成不变。
