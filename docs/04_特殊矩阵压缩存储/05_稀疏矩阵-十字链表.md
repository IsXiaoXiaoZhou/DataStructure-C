# 05_稀疏矩阵-十字链表


## 一句话定位

三元组顺序表存静态稀疏矩阵很好，可矩阵一做相加，非零元的位置和个数都会变：原来非零，相加抵消成 0 要删；原来为 0，相加出非零要插。顺序表插删得整片搬移，于是换成链表——每个非零元同时挂在一条行链和一条列链上，横竖交叉，得名十字链表。

## 核心概念

先把结构说全：rhead[0..rows-1] 各指向一行链首，chead[0..cols-1] 各指向一列链首；同一行的非零元按列号升序用 right 串成行链，同一列的按行号升序用 down 串成列链。每个结点带着 (row, col, value) 和 right、down 两个指针，下面这张图（.h 注释里原图）一眼看懂"十字"在哪：

```
rhead[0] → (1,1) ──right──→ (1,4) → NULL
rhead[1] → (2,1) ──right──→ (2,3) → NULL
   chead[0]        chead[2]
      ↓ down          ↓ down
    (2,1)           (3,3)
```

**为什么有了三元组还要十字链表**。矩阵相加、相乘时非零元会凭空出现或消失，顺序表里插一个元素要把后面整段搬一遍，删一个也要搬——动一次就是 O(tu)。更麻烦的是找插入位置：光知道第几行不够，还得知道同列的现状。十字链表让每个结点行、列两个方向都有序可循，沿行链走到列号够大的位置、沿列链走到行号够大的位置，两条链并行推进，前驱一找到，改两个指针就完成插删。

所以 set 是这个模块的全部戏份：拿 (i, j) 在行链和列链上**同时**找位置（prev_r、prev_c 两个前驱并行推进）；该位置已有结点则改值，改成了 0 就从两条链上各自摘下再 free；没有结点且值非零则 malloc 一个新结点，分别接进行链和列链的缝隙里。定位前驱是全部复杂度所在，指针改接本身只要 O(1)。get 就简单了，沿第 i 行的行链扫，列号越过 j 就可以提前停。

## 复杂度表

（ri、cj 记第 i 行、第 j 列的非零元个数，t 为非零元总数）

| 操作 | 时间 | 说明 |
| --- | --- | --- |
| matrix_init | O(rows + cols) | 建两套头指针数组 |
| matrix_get | O(ri) | 沿行链扫，列号越过 j 提前停 |
| matrix_set 插/删 | O(ri + cj) | 行列两链并行定位前驱，改接 O(1) |
| 存储空间 | O(t + rows + cols) | 每个非零元一个结点，另有两套头数组 |

## 易错点 / 考点

- 删除结点要摘两条链：只从行链解下来、忘了列链，那个已 free 的结点在列方向还挂着，之后遍历列链就是踩野指针。仓库 set 里 prev_c 那几行就是干这个的。
- 行链列链都有序，插的是"缝隙"不是表尾：新结点列号若小于行链中某个结点，得插到它前面，prev->right（或 prev->down）的改接顺序写漏一步就断链。手写插入代码时先画图标出 prev 和 cur 再动笔。
- 手画存储结构是考研高频题：容易漏画 rhead/chead 两个头指针数组，或者把方向画反——right 横着串行链（列号增大）、down 竖着串列链（行号增大），两句话记住。
- 对比记忆：三元组适合"建好就不怎么动"的矩阵，转置快（有快速版）；十字链表适合插删频繁的场景，代价是每结点多两个指针加两套头数组。题目问"何种场合选哪种"，就从非零元稳不稳定这个角度答。
