# 04 特殊矩阵压缩存储

## 是什么

特殊矩阵压缩存储研究如何把有规律分布（对称、三角、对角）或大量零元素（稀疏）的矩阵
压进一维数组或链式结构，而不是按 n×n 整块存储浪费内存。
本分类共 5 个模块：三种规则矩阵各给一套"矩阵下标 → 一维下标"的映射公式，
稀疏矩阵则提供三元组顺序表与十字链表两种存储。

## 现实用途

省内存地存稀疏/规则数据：图像、图的邻接关系、稀疏矩阵运算。

## 学习建议

按 对称矩阵 → 三角矩阵 → 对角矩阵 的顺序动手推导压缩映射公式（这是本章的核心考点），
再读稀疏矩阵-三元组理解行序存储以及普通/快速转置的差异，
最后读稀疏矩阵-十字链表体会十字交叉链表如何支持非零元的插删
（见[工程规范](/guide/conventions)）。
